## 1. 这是什么

**Boujoy Harness** 是给 **DSH（DeepSeek Harness）** 用的一个**界面主题**。

装上之后，你的 DSH 会变成：

- 🎬 **有品牌片头** —— 启动时播放一段开屏动画，而不是一闪而过的加载提示
- 🎨 **有自己的外观** —— 专属配色、字体、背景氛围
- ✨ **对话有动效** —— 消息和工具卡片的出现有节奏

它**只改变外观**，不会动你的会话、模型配置、工作区数据。
不想用了，一条命令卸载，界面立刻恢复原样。

## 2. 安装前你需要知道

### 2.1 环境要求

| 项 | 要求 |
|---|---|
| DSH 版本 | 见发布说明（本项目针对 `0.2.0-rc.2` 系列开发） |
| 操作系统 | Windows（桌面版）或任意支持浏览器访问的系统 |
| 使用方式 | DSH 桌面端，或 `dsh web` 浏览器模式 |

### 2.2 两个概念，先分清楚

DSH 把"配置"分成两层，看懂这两个词后面的命令就不难了：

- **profile（配置档）**：一套可启动的配置组合。你平时用的可能是 `web` 或 `desktop`。
  本项目**安装到 profile 里**。
- **bundle（组合包）**：提供功能的包。本项目就是一个 bundle。

> 💡 **重要**：`desktop` profile 由 DSH 桌面应用独占管理，命令行工具不能直接操作它。
> 如果你的 DSH 是桌面版，安装请参考 §3.2。

## 3. 安装

### 3.1 浏览器模式（`web` profile）

```bash
dsh plugin --profile web add <包名或本地 tgz 路径>
```

然后正常启动：

```bash
dsh web
```

启动后开屏动画与主题会自动加载，**不需要手动复制 CSS 或修改配置文件**。

### 3.2 桌面版

桌面版的 profile 由应用自己管理，因此**不要**用上面的命令行方式安装。

推荐流程：

1. 先用 §3.1 在 `web` profile 里装好并确认效果；
2. 再把该包加入桌面 profile 的 bundle 列表（配置文件位置：`<DSH_HOME>/profiles/desktop/package.json` 的 `dsh.profile.bundles`）；
3. **完全退出并重启 DSH 桌面应用**（不是刷新窗口）。

> ⚠️ 桌面端首次加载新插件必须重启应用，因为插件清单在进程内缓存。

### 3.3 从 GitHub 安装（版本未发布到 npm 时）

```bash
dsh plugin --profile web add github:<owner>/<repo>#<tag>
```

> ⚠️ 建议**锁定 tag**，不要跟随主分支，否则后续推送可能改变你实际运行的代码。

## 4. 首次启动你会看到什么

1. **开机片头**：从应用启动瞬间开始播放（不会先闪出 DSH 默认的加载提示）
2. **皮肤生效**：进入界面后，配色、字体、字标已是 Boujoy 风格
3. **氛围层**：背景有纹理/网格等装饰

**片头只播一次**：同一页面会话内刷新或切换会话**不会**重复播放。

## 5. 常用操作

### 5.1 跳过片头

| 方式 | 操作 |
|---|---|
| 临时跳过 | 点击片头上的「跳过」按钮（若该版本提供） |
| 永久关闭 | 见 §5.2 设置项 |

### 5.2 关闭/切换效果

| 想做什么 | 方式 |
|---|---|
| 关闭片头动画 | DSH 设置中的对应开关（若该版本提供），或卸载插件 |
| 恢复 DSH 原生外观 | 直接卸载（见 §6）即可，无需其他清理 |
| 只关动画保留配色 | 系统开启「减少动态效果」后，动画会自动降级 |

### 5.3 辅助功能

- 系统开启 **减少动态效果（prefers-reduced-motion）** 后，动画会自动降级或跳过
- 所有动效不影响键盘操作与焦点可见性

## 6. 自定义外观（★ 核心能力）

本项目最大的特点是：**你可以自己改外观，不需要写代码，也不会被插件升级覆盖。**

### 6.1 自定义内容放在哪里

一个独立目录，与插件本身分开：

```
$DSH_HOME/boujoy/
├── boujoy.config.yml     # 配置：颜色、动效、时长、字体路径
└── assets/               # 素材：logo、字体、背景、纹理
```

> `$DSH_HOME` 在 Windows 上通常是 `C:\Users\<你的用户名>\.dsh`。
> **这个目录不会被插件升级覆盖，卸载插件也不会删除它。**

### 6.2 换素材（最简单的自定义）

把文件放进 `$DSH_HOME/boujoy/assets/`，**文件名对上就生效**：

| 放这个文件 | 效果 |
|---|---|
| `logo.svg` | 换掉侧栏字标与开屏品牌标识 |
| `logo-mark.svg` | 换掉侧栏折叠时的小图标 |
| `fonts/brand.woff2` | 换掉品牌字体 |
| `textures/background.png` | 换掉背景氛围图 |
| `textures/grid.svg` | 换掉网格纹理 |

**只放你想改的**——没放的文件继续用内置默认。

> ⚠️ 字体必须是 `.woff2` 格式。其他格式需要先转换。
> ⚠️ 使用第三方字体/图片请自行确认授权。

### 6.3 改配色与动效（改一个配置文件）

编辑 `$DSH_HOME/boujoy/boujoy.config.yml`：

```yaml
name: "我的工作台"          # 侧栏与开屏显示的产品名
subtitle: "LOCAL AGENT OPS" # 开屏副标题

colors:
  brand: "#3ba7ff"          # 品牌主色

motion:
  splash:
    duration: 3.0           # 开屏时长（秒）
    skippable: true         # 是否允许跳过
  conversation:
    messageEnter: 240       # 消息入场动画时长（毫秒）
  ambience:
    intensity: 0.6          # 背景装饰强度 0–1
```

**所有字段都可以省略**，省略即用内置默认值。

### 6.4 完全自由（需要一点 CSS 知识）

在 `$DSH_HOME/boujoy/overrides.css` 里写任意 CSS，它会被注入到页面且优先级最高：

```css
:root {
  --bj-dur-normal: 300ms;   /* 改全局动效节奏 */
  --bj-grid-size: 96px;     /* 改网格大小 */
}
```

### 6.5 改坏了怎么办

| 情况 | 结果 |
|---|---|
| 配置写错（如把数字写成字母） | 会提示具体字段和行号；**界面仍可用**，那一项回退默认值 |
| 配置文件整体语法错 | 全部回退内置默认外观，并给出一次性提示 |
| logo 文件损坏 | 回退内置 logo |
| 字体加载失败 | 回退 DSH 官方字体 |
| 改得太乱想重来 | 直接删掉 `$DSH_HOME/boujoy/` 目录，立刻回到默认外观 |

> **底线：任何自定义内容出问题，界面都不会白屏或不可用。**

### 6.6 优先级规则

一句话：**越具体越优先，你永远压过内置。**

```
overrides.css  →  配置里的具体 token  →  配置里的简写（如 brand）  →  你放的素材  →  内置默认
   （最高）                                                                        （兜底）
```

### 6.7 安全模式

如果 DSH 升级到本项目尚未适配的版本，插件会进入**安全模式**：

- 只应用配色，**不注入自定义 CSS、不播放动画**
- 目的是：宁可少一些效果，也不让界面出问题
- 会在控制台/设置里提示原因

## 7. 升级与卸载

### 7.1 卸载（恢复原生外观）

```bash
dsh plugin --profile web remove <包名>
```

卸载后：

- ✅ 界面立即恢复 DSH 原生外观
- ✅ **不会**删除你的会话、模型配置、凭据或工作区数据
- ✅ **不会**删除 `$DSH_HOME/boujoy/` 里的自定义素材与配置（重装即恢复你的外观）
- ✅ 不会有残留样式或报错请求

> 如果卸载后仍有残留外观，请**完全重启 DSH**（插件样式在页面会话内生效）。

### 7.2 升级

```bash
dsh plugin --profile web update <包名>
```

升级后如未生效，重启 DSH。

## 8. 故障排查

| 现象 | 可能原因 | 解决办法 |
|---|---|---|
| 启动时**先闪一下** DSH 的 "Loading plugins…" 卡片再进片头 | 首帧注入未生效（插件未正确加载） | 确认插件已安装且 DSH 已重启；查看 §8 报告问题 |
| 片头**每次刷新都重播** | 去重未生效 | 报告问题（这属于 bug） |
| 界面**部分区域还是原样式** | 该区域未被主题覆盖 | 正常现象，可反馈希望覆盖的区域 |
| 界面**大片白底白字 / 看不清** | 对比度问题 | 报告问题（属 bug），临时可卸载恢复 |
| 安装后**完全没变化** | 插件未加载 | ①确认安装到了正确的 profile；②**完全重启** DSH；③桌面端需重启应用而非刷新 |
| 卸载后界面仍有残留 | 未重启 | 完全重启 DSH |
| 终端/某些面板显示异常 | 与第三方插件冲突 | 列出你装的其他插件，逐一排查 |

## 9. 如何反馈问题

报告时请附上：

1. **DSH 版本**（桌面版看「关于」，或命令行 `dsh --version`）
2. **操作系统与版本**
3. **本项目版本**
4. **复现步骤**：做了什么 → 期望什么 → 实际什么

## 10. 常见问题（FAQ）

**Q：会改我的会话记录或模型配置吗？**
A：不会。本项目只影响界面的表现层，所有数据仍在原位置。

**Q：和别的主题插件能同时装吗？**
A：不建议。多个主题会互相覆盖 token 和 CSS，结果不可预期。同时装也会增加排查难度。

**Q：我的 DSH 升级后主题坏了怎么办？**
A：DSH 目前是开发者预览版，官方明确会有破坏性变更。升级 DSH 后如果主题异常，
请先卸载主题确认原生界面正常，再查看本项目是否有新版本。

**Q：可以只装片头动画、不要皮肤吗？**
A：取决于发布形态。若提供独立开关则可；否则可卸载（片头与皮肤在同一条卸载路径上）。

**Q：字体是你们自带的吗？**
A：本项目使用的字体与素材授权信息会在发布说明中列出。若你所在场景有授权限制，
请以发布说明为准。

**Q：能装到公司电脑/分发给别人吗？**
A：取决于发布版本的许可声明。请查阅发布说明中的 License 部分。
